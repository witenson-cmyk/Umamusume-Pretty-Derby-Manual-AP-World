# Umamusume Pretty Derby Manual AP World
Manual AP World for the Mobile and PC game Umamusume: Pretty Derby updated for the Grand Live Scenario Update

* You are allowed to use any Rare Support Cards as well as any Borrowed Card
* Goal is to Perform the Final Concert with Special Hype
* Remove any locations if your account can't possibly complete them
  * Think 1600 training skill or S rank trainee
* Intended for a short 3-5 hour Sync

## What is Randomized:
* Access to Support Cards
  * Access to SSR and SR cards, as well as Card Types
* Access to Legacies
  * Before Progressive Legacies is unlocked, you have to use one of the starting G rank legacies, or whichever lowest legacies you have if you've gotten rid of them. Each Progressvie Legacy is another legacy slot.
* Access to Scenarios
  * Each Progressvie Scenario unlocks the next scenario in order, Unity Cup and then Trackblazer
* Access to Training Types and Recreation
  * You can Rest Freely
* Ability to Learn Skills
